## 硬性纪律

- 一切以计划文档为准；改架构/目录/工具链属重大决策，先决策矩阵 + 用户确认 + 落 decision_log。
- **fuzzy 条目在 msgfmt 与 babel 两条编译路径下默认都不进 .mo**——任何构建前 fuzzy 必须为 0；agent 修订 fuzzy 必须比对 `#|` 旧原文后清除标志。
- 只填 msgstr；msgid、位置注释、文件头禁改；`uv_*`/`UV_*`/`SIG*`/errno/文件名不译；内联标记原样保留且遵守**邻接规则**（起始前/结束后必须空白或全角标点）。
- msgid 以 `::` 结尾的条目：译文全角冒号「：」收尾，无需保留 `::`（已定案，勿再争论）。
- workdir 镜像布局不可变；网络纪律（gh api 直连优先，失败走代理 http://192.168.33.1:10808 回退一次；提权经 zcode-run）。
