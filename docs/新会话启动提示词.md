2. 检查上游 release 动态（upstream-watch.yml 每周一自动开 issue；也可 `gh api` 直查 latest release）：

     c. `gen_workdir.sh vX.Y.Z` → `make gettext` 重抽 pot（**msgid 总数比对**）→ `sphinx-intl update` 全量合并；

## 硬性纪律

- 一切以计划文档为准；改架构/目录/工具链属重大决策，先决策矩阵 + 用户确认 + 落 decision_log。
- **fuzzy 条目在 msgfmt 与 babel 两条编译路径下默认都不进 .mo**——任何构建前 fuzzy 必须为 0；agent 修订 fuzzy 必须比对 `#|` 旧原文后清除标志。
- 只填 msgstr；msgid、位置注释、文件头禁改；`uv_*`/`UV_*`/`SIG*`/errno/文件名/版本号不译；内联标记原样保留且遵守**邻接规则**；上游 role/指令残片（`c:func:`、`..note::` 类）按 **DR-005 族**逐字镜像处理，纯文本拼写笔误按语义正常译并登记。
- msgid 以 `::` 结尾的条目：译文全角冒号「：」收尾；`msgid "返回"`/`msgid "参数"` 为抽取工件，恒等译文处理（STYLE_GUIDE §2）。
- 术语以 glossary.md 为唯一依据（~221 条已冻结，修改既有译名属术语变更需登记并全量 sweep）。
- workdir 镜像布局不可变；改 overlay 后重跑 gen_workdir.sh（脚本自带 rm -rf workdir，幂等）；网络纪律（gh api 直连优先，失败走代理 http://192.168.33.1:10808 回退一次；提权经 zcode-run）。
